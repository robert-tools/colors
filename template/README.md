## Getting started

```bash
# 1. Clone / copy this template
# 2. Replace all occurrences of @scope/package-name with your package name

npm run check
```

## Scripts

| Command | Description |
|---|---|
| `npm run build` | Compile TypeScript to `dist/` |
| `npm test` | Run Jest tests with coverage |
| `npm run lint` | Run ESLint |
| `npm run check` | Lint + test + build (runs before publish) |
